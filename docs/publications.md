# 研究成果ページの更新

`/publications/` は `research-outputs/!summary` のExcelだけを元にする。
旧サイトの文字列データ、確認記録、PDF保存一覧からは補完しない。

## 取り込み

Pythonとopenpyxlを用意し、プロジェクトのルートで実行する。

```powershell
python scripts/import-publications.py 'C:/usr/Dev/research-outputs/!summary'
npm.cmd run build
python scripts/check-publications.py
```

元のExcelは読み取り専用で開く。生成する `src/data/publications.json` を差分確認し、サイトのソースと一緒に管理する。GitHub Pagesでのビルド時にはExcelやPythonは不要。

入力は `1論文誌.xlsx`、`2国際会議.xlsx`、`3国内会議.xlsx`、`4国内講演.xlsx`。生成データにファイル名・件数・SHA-256を残す。公開用の書誌項目だけを取り込み、内部メモ、著者の役割、PDF保存フラグ、ローカルパスは出力しない。PDFはコピーしない。

## 表示方針

- 日付の表示は年月までとする。月が空欄なら年のみ表示する。元データの日は保持し、並び替えには引き続き使用する。

- 論文誌は和文・英文を統合。国際会議、国内会議、国内講演は別区分。
- 空の区分は表示しない。2026-10-06取り込み時点で国内講演は0件。
- 各区分で年月日の降順。同日ならID順。月・日が空欄のものは同年・同月内の末尾へ置き、架空の日付は表示しない。
- 年別見出しを設け、番号は区分ごとに1から始めて年をまたいで継続する。
- Excelの将来の日付もそのまま掲載する。日付だけから採録・刊行状況を推定しない。
- 査読・招待・受賞情報は専用列の値で表示する。
- DOIとHTTP(S)のURLをリンクにする。URLは論文以外の会議ページの場合もあるので「関連ページ」とする。
- ページ欄の論文番号・講演番号・巻号を保持する。数字だけのページ範囲に限り `pp.` を添える。
