# 表示改善の相談メモ（2026-10-08）

## ページ冒頭の統一（実施済み）

現在、記事・メンバーは中央寄せ、研究成果は左寄せ、教員紹介は写真付きの専用構成。余白・見出しの文字サイズ・英語ラベルも個別に実装している。

通常の一覧ページ（記事・メンバー・研究成果・学位論文）は、共通の `src/components/PageHeader.astro` で「英語ラベル、日本語タイトル、短い説明」を左寄せに統一済み。
背景、見出しのサイズ、上下余白、本文との境界線も共通にし、件数などは必要なページだけ補足として表示する。
トップのヒーローと教員紹介の写真付き紹介、記事詳細の日付付き見出しは役割が異なるため、個別構成を保ちながら文字・余白の基本ルールを合わせる。

## 記事一覧

- 実施済み：年別見出し、年別・全体件数、年ジャンプリンク、年末の目次へ戻るリンク。公開日の降順は維持。
- 次の改善案：`/posts/` は最新年を表示し、過去年は `/posts/year/2025/` のような年別ページで読む。年を選ぶ操作が明確で、最初に表示する記事・画像も減らせる。記事詳細のURLは変更不要。
- 別案：全記事を20件程度ずつページ分割。年をまたぐと探しにくいため、このサイトでは年別ページを先に検討する。
- 年別ページ化は次の相談で決定する。今回の年ジャンプは全記事を1ページに掲載したままなので、全体の長さ自体は変わらない。
